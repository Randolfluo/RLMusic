# 执行报告：AI 智能套件「全站开场白」路由缺失修复

## 任务摘要

用户继续反馈「全站开场白」无法调用。经排查，根因为后端路由注册表中不存在 `POST /api/song/podcast/generate-all-public-playlist-intros`，前端 API 调用该接口直接返回 404。

## 根因分析

前端链路：
1. `AdminDashboard.vue:554` → `generateAllPublicPlaylistIntros()`
2. `src/api/ai.ts:110` → `POST /song/podcast/generate-all-public-playlist-intros`

后端路由 `server/internal/Manager.go` 中仅有：
- `POST /song/podcast/generate-playlist-intros/:id` — 按歌单 ID 生成（已有功能）
- **无** `POST /song/podcast/generate-all-public-playlist-intros` — 全量公共歌单生成（缺失）

## 修改文件清单

| 文件 | 操作 | 说明 |
|------|------|------|
| `server/internal/handle/handle_song.go` | 新增 handler | `GenerateAllPublicPlaylistIntros`：管理员权限检查 → 查询所有公共歌单 → 逐歌单遍历歌曲 → 调用现有 `generateAndSaveSongIntro` 逐首生成开场白 + TTS → 异步不阻塞 |
| `server/internal/Manager.go` | 新增路由 | 注册 `song.POST("/podcast/generate-all-public-playlist-intros", songAuthAPI.GenerateAllPublicPlaylistIntros)` |

## 关键变更说明

### 1. `handle_song.go` 新增 handler（位于 `BatchGenerateSongIntros` 之后、`generateAndSaveSongIntro` 之前）

```go
func (h *SongAuth) GenerateAllPublicPlaylistIntros(c *gin.Context) {
	// 1. 管理员权限检查
	user := GetCurrentUser(c)
	if user == nil || user.UserGroup != "admin" {
		ReturnError(c, g.ErrPermission, "只有管理员可以执行此操作")
		return
	}

	db := GetDB(c)

	// 2. 获取所有公共歌单
	var playlists []model.Playlist
	if err := db.Where("is_public = ?", true).Find(&playlists).Error; err != nil {
		ReturnError(c, g.ErrDbOp, "获取公共歌单失败")
		return
	}

	// 3. 异步执行
	go func(pls []model.Playlist, userID int) {
		for _, pl := range pls {
			var songIDs []int
			if err := db.Table("playlist_songs").Where("playlist_id = ?", pl.ID).Pluck("song_id", &songIDs).Error; err != nil {
				slog.Error("...")
				continue
			}
			if len(songIDs) == 0 { continue }

			for _, songID := range songIDs {
				if err := h.generateAndSaveSongIntro(db, strconv.Itoa(songID)); err != nil {
					slog.Error("生成歌曲开场白失败", ...)
				}
			}
			// 更新歌单 HasIntro 状态
			db.Model(&model.Playlist{}).Where("id = ?", pl.ID).Update("has_intro", true)
		}
	}(playlists, user.ID)

	ReturnSuccess(c, gin.H{
		"message": fmt.Sprintf("已开始后台生成 %d 个公共歌单的开场白", len(playlists)),
	})
}
```

### 2. `Manager.go` 路由注册（L177 之后）

```go
song.POST("/podcast/generate-playlist-intros/:id", songAuthAPI.BatchGenerateSongIntros)           // 批量生成歌单内歌曲开场白
song.POST("/podcast/generate-all-public-playlist-intros", songAuthAPI.GenerateAllPublicPlaylistIntros) // 批量生成所有公共歌单开场白
```

### 3. 复用设计

新 handler **完全复用**现有的 `generateAndSaveSongIntro(db, idStr)` 内部函数：
- `prompt_podcast1.md` → AI 分析
- `prompt_podcast2.md` → 草稿
- `prompt_podcast3.md` → 终稿
- `ai.SynthesizeAudio` → TTS（Neil 音色，flac）
- 保存 `description` + `opening_audio_file` 到 `songs` 表

无需新增 prompt 文件、无需新增 AI 调用逻辑、无需新增数据库字段。
