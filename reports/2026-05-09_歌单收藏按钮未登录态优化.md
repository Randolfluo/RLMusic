# 执行报告: 歌单收藏按钮未登录态优化

## 任务摘要

用户反馈在手机浏览器访问 Electron 服务端时,歌单详情页的"收藏"按钮不显示;Electron 客户端切到手机比例后同样不显示。经排查,根因是 **sessionStorage 中的登录态无法跨标签页/跨设备共享**,导致在新会话中 `user.userLogin` 为 `false`,原代码直接隐藏了收藏按钮,造成用户困惑。

本次修改将"未登录时直接隐藏"改为"未登录时显示'登录后收藏'按钮,点击后跳转登录页",提升移动端和跨设备访问时的用户体验。

## 修改文件清单

| 文件 | 操作 | 说明 |
|---|---|---|
| `src/views/Playlist/index.vue` | 修改 | 歌单详情页收藏按钮逻辑 |

## 关键变更说明

### `src/views/Playlist/index.vue`

1. **引入 `useRouter`**
   ```ts
   import { useRoute, useRouter } from "vue-router";
   const router = useRouter();
   ```

2. **拆分按钮显隐条件**
   - 原逻辑(单一 `v-if`):登录 + 歌单存在 + 不是自己的歌单 → 显示"收藏/取消收藏"
   - 新逻辑:
     - `v-if`:已登录 + 歌单存在 + 不是自己的歌单 → 显示"收藏/取消收藏"
     - `v-else-if`:未登录 + 歌单存在 → 显示"登录后收藏",点击 `@click="router.push('/login')"` 跳转登录页

3. **影响范围**
   - 仅影响歌单详情页 `/playlist/:id` 的头部操作区
   - 不改变已登录用户的收藏/取消收藏功能
   - 自己的歌单(拥有者不显示收藏按钮)行为保持不变

## 验证结果

- `vue-tsc --noEmit --skipLibCheck` 通过,无类型错误
- `vite build` 构建成功,无编译错误

## 遗留问题

- 本次仅修复了歌单**详情页**的收藏按钮体验。歌单网格/列表页([`PlaylistGrid.vue`](src/components/DataList/PlaylistGrid.vue))在未登录时长按/右键菜单同样不会显示"收藏"选项,属于一致性行为,如需统一优化可后续处理。
- 若用户期望**跨设备自动保持登录态**,需要后端支持 Cookie/RefreshToken 方案,超出本次修复范围。
