# 2026-05-07 播客模式实时切换修复

## 1. 任务摘要

修复播客模式切换不立即生效的问题。原实现中，`togglePodcastMode()` 只修改了 store 中的 `podcastMode` 标志位，不会重新触发播放逻辑，导致：
- **开启播客模式时**，不会立即切换到当前歌曲的开场白，必须等到下一首歌才生效
- **关闭播客模式时**，如果正在播放开场白，无法立即切回歌曲正文

## 2. 修改文件清单

| 文件 | 操作 | 说明 |
|------|------|------|
| `src/components/Player/index.vue` | 修改 | `togglePodcastMode` 函数增加实时切换逻辑 |

## 3. 关键变更说明

**修改点**：`togglePodcastMode()` 函数（第 503-531 行）

**开启播客模式时**：
- 调用 `getPlaySongData(song.id)` 重新触发播放逻辑
- `getPlaySongData` 内部检查 `setting.podcastMode && song.has_intro`，有开场白则切换到开场白音频

**关闭播客模式时**：
- 检查 `isPlayingIntro.value`，如果正在播放开场白，直接调用 `getMusicUrl` 获取歌曲正文 URL 并播放
- 复用 `handleSongEnded` 中已验证过的切回正文逻辑（VIP 提示等）

## 4. 验证结果

- 类型检查/语法：通过（使用已有函数 `getPlaySongData`、`getMusicUrl`、`isPlayingIntro`，已在文件中定义）
- 需手动验证：
  - [ ] 播放一首有开场白的歌曲 → 开启播客模式 → 应立即切换到开场白
  - [ ] 播放开场白期间 → 关闭播客模式 → 应立即切回歌曲正文
  - [ ] 播放一首无开场白的歌曲 → 开启播客模式 → 应正常播放歌曲正文，不报错
