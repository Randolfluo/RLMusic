# AI 描述字数调整及前端截断修复

## 1. 任务摘要

将 AI 生成的歌单/艺术家/专辑描述字数统一改为 60 字，并修复前端电脑端和移动端描述文本被省略号截断的问题，确保完整显示。

## 2. 修改文件清单

| 文件 | 操作 | 说明 |
|------|------|------|
| `server/prompts/prompt_playlist2.md` | 修改 | 描述字数 100→60 |
| `server/prompts/prompt_artist2.md` | 修改 | 描述字数 120→60 |
| `server/prompts/prompt_album2.md` | 修改 | 描述字数 120→60 |
| `src/views/Artist/index.vue` | 修改 | 移除 `<n-ellipsis>` 截断，移除未使用的 `NEllipsis` 导入 |
| `src/views/Album/index.vue` | 修改 | 移除 `.album-desc` 的 `-webkit-line-clamp: 2` |
| `src/views/Playlist/index.vue` | 修改 | 移除 `.playlist-desc` 桌面端 `-webkit-line-clamp: 2` 和移动端 `-webkit-line-clamp: 1` |

## 3. 关键变更说明

### Prompt 字数统一

三个 Step 2 描述生成 prompt 的字数要求全部改为 **60 字左右**：
- `prompt_playlist2.md`: `100字左右` → `60字左右`
- `prompt_artist2.md`: `120字左右` → `60字左右`
- `prompt_album2.md`: `120字左右` → `60字左右`

### 前端截断移除

- **Artist 页**: `n-ellipsis` 组件的 `line-clamp=3` 限制了描述最多 3 行，已移除组件包裹，描述完整显示
- **Album 页**: CSS `-webkit-line-clamp: 2` 限制 2 行，已移除
- **Playlist 页**: 桌面端 `2` 行、移动端 `1` 行的行数限制均已移除

## 4. 验证结果

- Go 代码格式检查通过（gofmt）
- 前端文件仅修改模板和样式，未涉及逻辑变更

## 5. 遗留问题

- 旧数据中已生成的超长描述需要重新生成才会缩短至 60 字
