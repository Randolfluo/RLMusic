# 执行报告：修复移动端红心收藏与歌单页收藏按钮

## 任务摘要

用户反馈两个问题：
1. **移动端首页点击红心无法收藏歌单** — 在首页/歌单列表页的移动端列表视图中，点击歌单右侧红心无响应。
2. **歌单页没有收藏按钮** — 歌单详情页收藏按钮因类型不匹配可能异常显示/隐藏；桌面端网格视图中红心依赖 CSS hover，触摸设备上不可见。

## 修改文件清单

| 文件 | 操作 | 说明 |
|------|------|------|
| `src/components/DataList/PlaylistGrid.vue` | 修改 | 预加载收藏状态、修复 owner_id 检查、修复类型匹配、添加 hover:none CSS |
| `src/views/Playlist/index.vue` | 修改 | 修复收藏按钮 v-if 类型匹配 |

## 关键变更说明

### 1. `PlaylistGrid.vue` — 预加载收藏状态（L180-206）

将原来的单一 `watch` 拆分为两个独立的监听器，解决**用户登录时序问题**：

- **`watch(() => props.playlists, ...)`**：当父组件传入的歌单列表变化时加载收藏状态
- **`watch(() => userStore.userLogin, ...)`**：当用户登录状态变为 `true` 时加载收藏状态

原实现仅监听 `props.playlists`，若页面加载时用户未登录（token 未恢复），watch 直接 return。用户后续登录后 `props.playlists` 未变化，watch 不重新触发，`isSubscribedMap` 始终为空，导致红心不显示或点击无效。

```typescript
const loadSubscribedStatus = async () => {
    if (!userStore.userLogin || !props.playlists?.length) return;
    try {
        const res = await getSubscribedPlaylists();
        if (res.code === ResultCode.SUCCESS) {
            const subscribedIds = new Set((res.data || []).map((p: any) => p.id));
            for (const item of props.playlists) {
                if (item.id && Number(userStore.userData.userId) !== Number(item.owner_id)) {
                    isSubscribedMap.value[item.id] = subscribedIds.has(item.id);
                }
            }
        }
    } catch (e) {
        console.error(e);
    }
};

watch(() => props.playlists, loadSubscribedStatus, { deep: true });
watch(() => userStore.userLogin, (loggedIn) => {
    if (loggedIn) loadSubscribedStatus();
});

### 2. `PlaylistGrid.vue` — 移动端红心添加 owner_id 检查（L36-41）

移动端列表视图的红心按钮原先无条件显示，现添加 `owner_id` 检查，自己的歌单不显示红心：

```vue
<div
  v-if="userStore.userLogin && Number(userStore.userData.userId) !== Number(item.owner_id)"
  class="item-action"
  @click.stop="handleLike(item)"
>
```

### 3. `PlaylistGrid.vue` — 修复 handleLike 类型匹配（L254-256）

将 `userStore.userData.userId === item.owner_id` 改为 `Number(userStore.userData.userId) === Number(item.owner_id)`，避免字符串/数字类型不匹配导致的判断错误。

### 4. `PlaylistGrid.vue` — 触摸设备红心始终可见（L731-735）

桌面端网格视图中，未收藏歌单的红心默认 `opacity: 0`，仅在 `hover` 时显示。在无法 hover 的触摸设备（平板等）上，红心完全不可见。新增 CSS：

```css
@media (hover: none) {
    .playlist-card .like-btn {
        opacity: 1;
        transform: translateY(0);
    }
}
```

### 5. `Playlist/index.vue` — 修复收藏按钮类型匹配（L80）

将 `playlist.owner_id !== user.userData.userId` 改为 `Number(playlist.owner_id) !== Number(user.userData.userId)`，确保类型一致后比较。

## 验证结果

- **TypeScript 编译**：`npx vue-tsc --noEmit` exit code 0，无类型错误
- **功能预期**：
  - 页面加载时已登录 → 歌单列表自动加载收藏状态，已收藏歌单红心显示为红色
  - 页面加载后登录 → 登录态变化触发收藏状态加载，红心正确显示
  - 点击已收藏歌单红心 → 取消收藏成功
  - 点击未收藏歌单红心 → 收藏成功
  - 自己的歌单在移动端列表中不显示红心
  - 歌单详情页收藏按钮按 owner_id 正确显示/隐藏
  - 触摸设备上歌单卡片的红心始终可见

## 遗留问题

- **页面加载后登录场景**：`Home/index.vue` 中公共歌单的 `PlaylistGrid` 在用户未登录时已渲染。当用户登录后，新增的 `userStore.userLogin` watch 会触发收藏状态加载。但首次登录时 `getSubscribedPlaylists()` 可能返回空列表（用户还没有收藏），这是预期行为。后续收藏操作正常。
