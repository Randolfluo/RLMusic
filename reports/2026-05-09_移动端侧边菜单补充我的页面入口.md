# 执行报告：移动端侧边菜单补充"我的"页面入口

## 任务摘要

用户反馈移动端（汉堡菜单侧边栏）的"我的"页面不支持显示桌面端下拉菜单中的功能入口，包括"我喜欢的音乐"、"收藏的歌单"、"播放历史"。

根因为 `Nav/index.vue` 的移动端侧边抽屉菜单（`n-drawer`）中仅包含"我的"一个入口，缺少桌面端 `userOptions` 下拉菜单中的三个子功能。

## 修改文件清单

| 文件 | 操作 | 说明 |
|------|------|------|
| `src/components/Nav/index.vue` | 修改 | 移动端侧边菜单补充 3 个功能入口 + 2 个图标导入 |

## 关键变更说明

### 1. 移动端侧边菜单补充入口（L131-145）

在"我的"菜单项之后、"连接服务"之前，新增 3 个菜单项：

```vue
<n-list-item @click="router.push('/like'); showMobileMenu = false">
  <template #prefix><n-icon :component="Like" /></template>
  我喜欢的音乐
</n-list-item>
<n-list-item @click="router.push('/likeplaylist'); showMobileMenu = false">
  <template #prefix><n-icon :component="FolderPlus" /></template>
  收藏的歌单
</n-list-item>
<n-list-item @click="router.push('/history'); showMobileMenu = false">
  <template #prefix><n-icon :component="History" /></template>
  播放历史
</n-list-item>
```

### 2. 图标导入补充（L159-173）

```diff
  import {
    ...
    HamburgerButton,
+   Like,
+   FolderPlus,
  } from "@icon-park/vue-next";
```

`History` 图标已在原有导入中存在，无需新增。
